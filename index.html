云端同步设置（Supabase）

建表 SQL：
create table yubao_data (id text primary key, payload jsonb, updated_at timestamptz default now());
同步密钥留空时，每台设备的云端数据相互独立、互不可见；多台设备想共享同一份数据，就都填同一个密钥。别人不知道你的密钥就进不了你的空间。
填入后点击连接，状态栏会显示「云端已连接」。
